# Definition of Done (DoD)

Este documento estabelece os critérios obrigatórios que cada funcionalidade ou tarefa deve atingir para ser considerada **concluída** e pronta para entrega.

## ✅ Critérios de Aceite Técnicos

- [ ] **Código & Versionamento:** Código enviado para o repositório na branch correta e Pull Request aberto.
- [ ] **Qualidade de Código:** Sem erros de Lint ou Typecheck (TypeScript).
- [ ] **Build:** O projeto deve compilar com sucesso tanto localmente quanto no Docker.
- [ ] **Segurança:** Nenhuma credencial (senhas, chaves de API, segredos do `.env`) deve estar exposta no código.
- [ ] **Revisão:** O código foi revisado por pelo menos um colega de equipe (Peer Review).

## ⚙️ Funcionalidade e Negócio

- [ ] **Regras de Negócio:** Todas as validações e permissões de acesso foram implementadas no backend.
- [ ] **Testes Manuais:** O fluxo principal foi testado com sucesso no ambiente local.
- [ ] **Requisitos:** A entrega atende a todos os critérios de aceite definidos na Sprint.

## 📚 Documentação e Entrega

- [ ] **Arquitetura:** Caso existam novas rotas ou mudanças no banco, a documentação foi atualizada.
- [ ] **UML:** Se o fluxo mudou, os diagramas de sequência ou classe foram refletidos nos assets.
